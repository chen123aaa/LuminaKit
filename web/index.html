LuminaKit

GlowButton — light that follows

A button whose soft glow and rim highlight track the pointer, with a short trailing lag so the light feels like it has weight. Pure CSS and vanilla JS, no dependencies.

Usage

<!-- 1. stylesheet -->
<link rel="stylesheet" href="glow-button/lumina-glow-button.css">

<!-- 2. markup -->
<button class="lg-btn">Continue</button>

<!-- 3. behaviour (auto-initialises every .lg-btn) -->
<script src="glow-button/lumina-glow-button.js"></script>
/* tune it with CSS custom properties */
.lg-btn {
  --lg-glow: 182 156 255;   /* r g b */
  --lg-glow-size: 200;       /* trailing glow radius, px */
  --lg-glow-alpha: 1;         /* strength */
  --lg-radius: 14;            /* corner radius, px */
}
